System goal:
Evaluate multiple backend jobs for one candidate and return compact machine-readable JSON.

Inputs:
Candidate profile:
{candidate_profile}

Evaluation rules:
{evaluation_rules}

Jobs:
{jobs_block}

Required reasoning targets per job:
1. Profile fit and core skill match.
2. Score 0-100.
3. Recommendation: Apply / Consider / Skip.
4. Relative rank across all jobs (1 = best).

Output contract (strict):
- Return JSON only. No markdown. No prose outside JSON.
- Include one result for each provided JOB_ID.
- Keep summary short (<= 180 chars, plain text).
- If unsure, still return best-effort values. Do not omit a job.

JSON shape:
{{
  "jobs": [
    {{
      "job_id": "JOB_ID from input",
      "recommendation": "Apply|Consider|Skip",
      "score": 0,
      "rank": 1,
      "summary": "short explanation"
    }}
  ],
  "top_picks": ["job_id_1", "job_id_2"]
}}
